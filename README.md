# canvas-skill

A skill that lets Claude Code, Codex, or ChatGPT create and edit [Vibe Canvas](https://vibe.us) boards, then review the layout.

To install, give your assistant this link: https://github.com/vibeus/canvas-skill/blob/main/skills/install.md

The skill itself lives in [`skills/vibe-canvas`](skills/vibe-canvas).
